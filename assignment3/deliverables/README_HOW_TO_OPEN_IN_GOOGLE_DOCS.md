# How to open this report in Google Docs

1. Download the file: `Assignment3_Application_Installation_and_Configuration.docx`
2. Open https://docs.google.com
3. Click **File → Open → Upload**
4. Select the `.docx` file
5. Google Docs will convert it — you can edit text, table, and images
6. To download again: **File → Download → Microsoft Word (.docx)** or **PDF**
