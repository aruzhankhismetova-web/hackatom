# NEARLY

Маркетплейс начинающих специалистов в Атырау. Не каталог организаций: мастера публикуют свободные часы, клиенты бронируют конкретное время.

Сейчас в ленте учебные анкеты: фотограф, мастер маникюра, репетитор, дизайнер, видеограф и визажист. Своя анкета, новый час и бронь сохраняются в браузере.

Деньги устроены так: клиент платит мастеру цену из ленты, NEARLY берёт комиссию с записи. Подписка специалиста снижает комиссию и поднимает час внутри того же дня.

## Запуск

```bash
npm install
npm test
npm run dev
```

Сайт откроется на `http://127.0.0.1:5173`.
