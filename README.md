# TilTekser

Контроль качества казахской и узбекской локализации мобильной игры и выверенный казахский перевод.

Инструмент читает строки (JSON, CSV, Excel, PO), находит поломки, из‑за которых текст нельзя выпускать, и отдаёт эталон `kk` с пояснением каждой правки. Учебный корпус повторяет интерфейс открытого мира: меню, магазин, фракции, чат, машины, баны. Это не выгрузка из клиента Grand Mobile.

## Что сдаётся

| Артефакт | Где |
| --- | --- |
| Проверки kk и uz | `python -m qazaq_loc_qa` |
| Отчёт | `reports/before/report.html` |
| Выверенный казахский | `data/corrected/kk.json` |
| Почему так | `data/corrected/REVIEW.md` и `review.csv` |
| Глоссарий | `data/glossary/terms.json` |
| Веб-интерфейс | `streamlit run app.py` |
| Защита | `slides/index.html` |

## Запуск

Нужен Python 3.10 или новее. Если команды `python` нет, везде ниже подставьте `python3`. Отчёт и эталон собираются стандартной библиотекой:

```bash
python -m qazaq_loc_qa demo
```

Появятся `reports/before` (ошибки корпуса) и `reports/after` (тот же корпус после подстановки казахского эталона и механической правки узбекского апострофа). В казахском после правки не должно остаться critical и high.

Свой файл:

```bash
python -m qazaq_loc_qa check path/to/strings.json --out reports/my
python -m qazaq_loc_qa fix path/to/strings.json --out reports/fixed
```

`fix` подставляет `data/corrected/kk.json`, если ключи совпали. Чужой файл без этих ключей получит только безопасную чистку пробелов. Свой эталон: `--corrections my-kk.json` (объект «ключ → текст»).

Excel и веб-интерфейс:

```bash
pip install -r requirements.txt
streamlit run app.py
```

В боковой панели можно открыть учебный корпус или загрузить JSON, CSV, XLSX, PO.

Слайды листаются стрелками: `slides/index.html`.

Тесты:

```bash
pip install pytest openpyxl
python -m pytest -q
```

## Что именно ищется

Критично: пустой перевод, битая кодировка, другой набор `%s` / `{name}` / `%1$d`, сломанные `<b>` и `<color>`, строка, которая так и осталась английской.

Высокий приоритет: копия русской строки, термин не из глоссария, русское слово в казахском, нарушение сингармонизма (`үйлар`, `үйға`, `дослар`), буквы ё ъ щ, латиница внутри казахской строки, кириллица в узбекском.

Средний: пробелы, пробел перед `?`, слишком длинная короткая кнопка, апостроф `o'` / `g'` вместо `oʻ` / `gʻ`.

Языковая модель не обязательна. Если задать `OPENAI_API_KEY` (или `QAZAQ_LLM_API_KEY`) и запустить `check --llm`, модель добавляет смысловые замечания вторым слоем. Без ключа отчёт строится только правилами. Пример переменных — в `.env.example`.

## Казахский эталон

Правки в `data/corrected/kk.json` следуют таким решениям:

- системные фразы на «сіз», кнопки короткие;
- свои слова вместо кальки: тапсырма, заттар, алтын, сандық, жанармай, көлік, бейне, құпиясөз, марапат;
- заимствования, которые уже звучат в игре, оставлены: гараж, сервер, полиция;
- плейсхолдеры и теги источника не трогаются;
- ряд гласных и согласный перед окончанием проверяются тем же чекером, что и баги.

`REVIEW.md` заканчивается пустой подписью носителя. Инструмент эту подпись не рисует сам.

Узбекские формулировки в `uz_suggestions.json` — рекомендация латиницей. Обязательный эталон трека — казахский.

## Форматы

- Список объектов с полями `key`, `en`, `ru`, `kk`, `uz`, `context`.
- Объект «ключ → текст» в файле `kk.json` / `en.json`.
- Вложенный JSON (`ui.play`) раскладывается в точки.
- CSV и первый лист Excel с теми же колонками.
- PO: `msgctxt` — ключ, `msgid` — английский, `msgstr` — язык из имени файла или заголовка `Language`.

В папке сначала читается `strings.json` / `strings.csv` / `strings.xlsx`, затем одноязычные файлы только дополняют пустые ячейки.
