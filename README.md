# Sóz

Проверка локализации мобильной игры «Алтын Жол»: қазақша и oʻzbekcha.

Инструмент читает JSON, CSV, Excel и PO, отдельно закрывает технические поломки и отдельно — смысл. Смысловой слой не перепроверяет `%s`, `{name}`, теги и үндестік. На чистой строке он молчит.

## Запуск

```bash
python3 -m pip install -r requirements.txt
python3 check_loc.py samples --ai local
python3 check_loc.py --eval
```

Отчёт пишется в `reports/report.html` и `reports/report.json`. Код выхода `1` значит, что в файлах есть критичная находка (пустой перевод, битая кодировка, сломанный плейсхолдер или тег). Сам отчёт при этом уже записан.

На корпусе из `samples/` сейчас 62 строки и 37 находок, из них 5 критичных. `samples/clean_kk.json` должен проходить без замечаний.

## Что проверяет технический слой

| Код | Что ловит |
| --- | --- |
| `placeholder_mismatch` | `%s`, `%d`, `%1$s`, `{name}`, `{player}` разъехались с источником |
| `tag_mismatch` | сломанные или потерянные `<b>`, `</b>` |
| `vowel_harmony`, `consonant_harmony` | буын үндестігі и дыбыс үндестігі: Үйда → Үйде, Кітаплер → Кітаптар, Әнлер → Әндер |
| `number_plural` | көптік после числа: `{count} өмірлер` → `{count} өмір`, `3 тиындар` → `3 тиын` |
| `uz_plural_suffix`, `uz_locative`, `uz_dative`, `uz_apostrophe` | `-ler` → `-lar`, `uyde` → `uyda`, `yurakga` → `yurakka`, `oʻ`/`gʻ` через U+02BB |
| `uz_double_plural` | `3 ta kitoblar` → `3 ta kitob` |
| `script_mix`, `untranslated`, `mojibake` | чужой алфавит, строка не переведена, битая кодировка |

Буквы ö ğ ş ç до 22 апреля 2027 не считаются ошибкой.

## Смысловой слой

Промпт собран из трёх файлов, а не из одной простыни в коде:

- `prompts/system.md` — зона модели и запреты
- `prompts/game_context.md` — контекст «Алтын Жол» и спорные термины
- `prompts/few_shot.json` — эталон, версия `soz-ai-2`

Модель видит не весь глоссарий, а срез терминов, которые реально есть в строке, плюс контекст: кнопка, диалог, тост или выход. Плейсхолдеры перед запросом заменяются на `⟦0⟧`, `⟦1⟧` и после ответа возвращаются на место.

Калибровка, которую держит `python3 check_loc.py --eval`:

| Строка | Решение |
| --- | --- |
| Ойнау, «Сен қайдасың?», «Sen qayerdasan?», uyda, «Сен сыйлық алдың» | молчать |
| «Сенімдісіз бе?» | «Растайсыз ба?» |
| «Сенімдісіз ма?» в вопросе выхода | «Шыққыңыз келе ме?» |
| «Кнопке басыңыз» | «Батырманы басыңыз» |
| «Siz ishonchingiz komilmi?» про выход | «Chiqasizmi?» |
| «Ishonchingiz komilmi?» про покупку | молчать: это не выход |

Ограждения отбрасывают ответ модели, если он:

- теряет или меняет `%s`, `%d`, `{name}`, `<b>`
- предлагает «Сіз сыйлық алдың» — формальное сіз требует «алдыңыз», а глагол тоста не трогают
- подставляет запрещённый термин из глоссария
- придумывает замечание к строке, которую эталон считает чистой

Без ключа те же решения принимает локальный ревьюер: он читает `few_shot.json` и глоссарий. Это не заглушка «всегда пусто», а высокий порог точности для известных ошибок.

С ключом модель зовётся только на хвост: русская калька, которую правила ещё не закрыли. Уже найденную правку она не переписывает. Ответ проходит те же ограждения.

```bash
export OPENAI_API_KEY=...
export OPENAI_BASE_URL=https://api.openai.com/v1
export OPENAI_MODEL=gpt-4o-mini
python3 check_loc.py samples --ai auto
```

`--ai off` оставляет технику и глоссарий. `--ai local` не ходит в сеть. `--ai api` без ключа сам сваливается на локальные правила.

Глоссарий лежит в `glossary/kk.json` и `glossary/uz.json`. Для экрана настроек норма — баптау, не орнату и не реттеу. Подарок — сыйлық, квест — тапсырма, энергия — қуат, клан — одақ, кристалл — асыл тас, валюта — тиын. Болдырмау — это undo, не кнопка отмены. Қоржын в меню не используется. В uz пароль — parol, меню — menyu, пауза — pauza, друг — doʻst, персонаж — qahramon: это отдельные нормы, а не ошибка относительно kk.

Если один английский источник в одном файле переведён двумя словами, отчёт ставит `glossary_inconsistency`. В образце это Settings → «Настройкалар» и «Реттеулер».

## Структура

```
check_loc.py          основной скрипт
src/soz/parse.py      JSON, CSV, Excel, PO
src/soz/technical.py  плейсхолдеры, теги, числа, алфавит
src/soz/harmony.py    үндестік и узбекская морфология
src/soz/glossary.py   термины и единообразие
src/soz/ai/           промпт, ревьюер, клиент, ограждения
glossary/             kk.json, uz.json
prompts/              system.md, game_context.md, few_shot.json
samples/              корпус и gold.json
```

Свой файл:

```bash
python3 check_loc.py path/to/file.json --locale kk --glossary glossary --out reports
```

В JSON подходит список объектов `{key, source, target, context}`, объект с полем `entries` или плоский словарь «ключ → перевод». В CSV и Excel нужны колонки `key`, `source`, `target`, `context`. В PO источник — `msgid`, перевод — `msgstr`, ключ берётся из ссылки `#:`.

## Ограничения

Локальные правила закрывают кальки и термины, которые записаны в эталоне и глоссарии. Свободный смысл длинной реплики без этих признаков остаётся модели, и только если задан `OPENAI_API_KEY`. Гармония не трогает слово короче порога и не «чинит» термин, который уже забрал глоссарий: «Настройкалар» становится «Баптаулар», а не «Настройкатар».
