4. Troubleshooting

Scenario A — Installation error

Problem: installer fails. Causes: corrupt download, permissions, conflict, security block, wrong arch. Solution: read error, re-download official installer, elevate privileges, clear partial install, check docs. Verify: install completes; app launches with correct version.

Scenario D — Missing dependency

Problem: missing runtime/library. Causes: runtime absent/wrong version, broken libs. Solution: identify from error/docs/ldd/apt depends; install from official repo; avoid untrusted downloads. Verify: app starts; dependency listed.
