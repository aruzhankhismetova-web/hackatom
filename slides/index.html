01

TilTekser

Контроль качества казахской и узбекской локализации для Grand Mobile.

Игрок в Алматы и Ташкенте не должен видеть сломанный плейсхолдер, русскую кальку и «Үйлар» вместо «Үйлер».

02

Две задачи трека

Инструмент ищет ошибки. Эталон казахского уже лежит в репозитории.

1. Автопоиск

kk и uz: плейсхолдеры, теги, кодировка, пустые строки, сингармонизм, глоссарий, калька.

2. Выверенный kk

Отдельный файл перевода, ревью каждой правки и место для подписи носителя.

03

Что ломается в мобильном UI

Ошибка локализации — это не только «некрасивое слово».

  • %s и {name} нельзя терять: клиент падает или показывает чужое имя.
  • Незакрытый <color> закрашивает весь экран.
  • Ð¡Ð°ÑÑÐ¿ — битая кодировка, строка нечитаема.
  • «Квест», «донат», «инвентарь» разъезжаются между экранами.
  • Длинная кнопка обрезается на узком телефоне.

04

Как устроен прогон

Сначала техника, потом язык, потом человек.

  1. Парсер читает JSON, CSV, Excel или PO и склеивает en / ru / kk / uz по ключу.
  2. Технические чекеры сравнивают плейсхолдеры, теги и переводы строк с английским.
  3. Казахский чекер смотрит сингармонизм, чужие буквы и русские слова.
  4. Узбекский чекер ждёт латиницу и апостроф oʻ / gʻ.
  5. Глоссарий держит один термин на всю игру.
  6. Модель подключается только если есть API-ключ и не подменяет эти правила.

05

Цифры учебного корпуса

Один и тот же прогон до правки и после эталона kk.

93

находок до правки, оценка 0/100. Из них critical: 19. kk: 65, uz: 28.

0 kk

находок в казахском после эталона. В uz осталось 22, из них critical 8: это ещё работа носителя узбекского.

Казахский эталон проходит те же чекеры, которыми мы ловим баги. Серьёзных kk-находок после правки нет.

06

Казахский, которым можно играть

Не подстрочник, а язык интерфейса.

  • Играть → Ойнау, настройки → Баптаулар, отмена → Бас тарту.
  • Квест → тапсырма, инвентарь → заттар, донат → алтын, кейс → сандық.
  • Үйлер, үйге, достар — ряд и согласный окончания проверяются правилом, не «на глаз».
  • Гараж, сервер и полиция оставлены: так эти слова уже живут в игре.
  • Каждая правка записана в data/corrected/review.csv парой «было → стало».

07

Запуск за одну команду

Зависимостей для отчёта нет: хватает Python 3.10+.

python -m qazaq_loc_qa demo
python -m qazaq_loc_qa check data/sample/strings.json
pip install -r requirements.txt
streamlit run app.py

Веб-интерфейс принимает свой JSON, CSV, XLSX или PO и отдаёт HTML-отчёт и исправленный kk.

08

Граница инструмента

Чекер не заменяет редактора. Он не даёт багу доехать до билда.

  • Смысловые тонкости модель смотрит только по запросу и только как второй слой.
  • Узбекский эталон в репозитории — рекомендация. Подпись носителя uz в треке не требуется, для kk место подписи есть.
  • Учебный корпус повторяет форматы и баги мобильной локализации. Это не выгрузка из клиента Grand Mobile.
  • Студии инструмент нужен в CI: critical по плейсхолдерам и тегам блокирует сборку.
